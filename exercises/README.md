# Exercises

One drill per week. Do them in order, in a scratch directory (`~/git-practice`)
unless the drill says otherwise — you don't want practice garbage in this repo's
history, except where the drill explicitly asks you to commit here.

Each drill ends with **checkpoint questions**. If you can't answer them without
looking, redo the drill rather than moving on.

## Before you start a drill

Cheatsheet **closed**. Attempt each command from memory, and predict what it
will do to the working tree, the index, and HEAD before you press enter. Check
with `git status` and `git lg`. Wrong predictions are the most useful thing that
can happen to you here — see
[`../makeitstick/principles.md`](../makeitstick/principles.md).
